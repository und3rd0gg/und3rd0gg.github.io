Быстрые заметки
на Windows

Быстрый блокнот для Windows. Нажмите Alt + A, запишите мысль и вернитесь к своим делам. Заметки, которые стоит сохранить, отправьте в Obsidian.

Установить из Microsoft Store↗ Помочь улучшить приложение ↓

Скачать бесплатно · Для локальных заметок аккаунт не нужен

01 / ЗАПИШИТЕ

Записывайте без подготовки

Небольшое окно всегда под рукой. Сохраните черновик ответа, мысль со встречи или короткий список дел без выбора папки.

02 / ОБДУМАЙТЕ

Разберитесь в деталях

Обычный текст, задачи Markdown и быстрые расчёты. Работайте с локальными заметками без входа в аккаунт и включения синхронизации.

03 / СОХРАНИТЕ ВАЖНОЕ

Отправьте в Obsidian.

Выберите локальное хранилище Obsidian и отправляйте туда важные заметки. Также можно экспортировать их в Markdown или обычный текст.
